# تدفقات الذهب

لوحة تعرض حيازات الذهب وتغيّراتها: الدول، البنوك المركزية، البنوك التجارية (CFTC COT)، مخزون COMEX، وصندوق GLD.

- `index.html` صفحة اللوحة.
- `fetch_gold.py` يجلب البيانات ويكتب `data.json`.
- `.github/workflows/update.yml` يشغّل الجلب تلقائيًا كل يوم عمل.
- اللغات: العربية وEnglish وItaliano وEspañol (زر اللغة أعلى الصفحة، أو `?lang=it` في الرابط).
- التقرير الذكي يكتبه Claude Fable باللغات الأربع، ويختم بانحيازه وثلاثة احتمالات مقدّرة بالنسبة المئوية.

إذا ظهر تحذير أحمر في أحد الأقسام، افتح تبويب Actions، ثم آخر تشغيل، ثم خطوة «جلب البيانات»، وانسخ السطور التي تبدأ بـ `[gold]`.
