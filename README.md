# تدفقات الذهب

لوحة تعرض حيازات الذهب وتغيّراتها: الدول، البنوك المركزية، البنوك التجارية (CFTC COT)، مخزون COMEX، وصندوق GLD.

- `index.html` صفحة اللوحة.
- `fetch_gold.py` يجلب البيانات ويكتب `data.json`.
- `.github/workflows/update.yml` يشغّل الجلب تلقائيًا كل يوم عمل.
- أقسام جديدة: «العوائد والدولار» (FRED وDXY)، و«GEX (GLD)» من خيارات Cboe المؤجلة، وسجل أداء انحياز التقرير الذكي (يُقيَّم بعد 14 يومًا بمقياس Brier).
- كل مصدر يُفحص قبل النشر (قفزات غير منطقية، فجوات تواريخ، قيم خارج المدى)؛ عند الخطأ تبقى آخر بيانات سليمة ويظهر تحذير.
- المنصة بالعربية فقط.
- التقرير الذكي يكتبه Claude Opus 5.5 كل يوم عمل الساعة 13:30 بتوقيت فيينا، ويختم بانحيازه وثلاثة احتمالات مقدّرة بالنسبة المئوية.
- الوصف الكامل للمنصة ومبادئها وقواعد تقييمها في `CONSTITUTION.md`.

إذا ظهر تحذير أحمر في أحد الأقسام، افتح تبويب Actions، ثم آخر تشغيل، ثم خطوة «جلب البيانات»، وانسخ السطور التي تبدأ بـ `[gold]`.
